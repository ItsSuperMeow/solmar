Solmar is an original open-world crime game for the make.fun GTA 6 bounty: a sun-soaked coastal city to explore on foot and by car, with traffic, pedestrians, a wanted level and police, missions and a story, combat, and a HUD with a minimap. Play it in a desktop browser from static files, no network needed.
